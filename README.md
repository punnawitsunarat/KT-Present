# KT-Present

เว็บซ้อมตอบคำถามพรีเซน CIP สำหรับมือถือและไอแพด

- ผู้ชมเลือกสไลด์ เปิดคำตอบ และสุ่มซ้อมได้จากลิงก์เว็บ
- เจ้าของเปิดลิงก์แก้ไขส่วนตัวเพื่อเพิ่ม แก้ไข ลบ และเลิกทำการลบคำถาม
- คำถามที่บันทึกผ่าน Supabase จะแสดงบนทุกเครื่องที่เปิดเว็บ ส่วนสถานะการซ้อมเก็บในเบราว์เซอร์
- หากเคยแก้คำถามก่อนเปิดซิงก์ ให้เปิดลิงก์แก้ไขจากเบราว์เซอร์เดิม แล้วกด **นำเข้าคำถามจากเครื่องนี้** เพื่อรวมเข้าชุดกลาง

เว็บใช้ HTML, CSS และ JavaScript บน GitHub Pages จาก `main` ที่ `/ (root)` และอ่านคลังคำถามสาธารณะจาก Supabase ด้วย publishable key การเขียนผ่านฟังก์ชันที่ตรวจคีย์จากลิงก์แก้ไขและตรวจ revision ก่อนบันทึก

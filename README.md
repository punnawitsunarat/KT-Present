# KT-Present

เว็บซ้อมตอบคำถามพรีเซน CIP สำหรับมือถือและไอแพด

- เลือกสไลด์ด้วยภาพย่อ
- เปิด–ซ่อนคำตอบ สุ่มคำถาม และเก็บข้อที่ยังไม่คล่อง
- เพิ่ม แก้ไข ลบคำถาม และเลิกทำการลบ
- คำถามและสถานะบันทึกใน localStorage ของแต่ละเบราว์เซอร์ ไม่ซิงก์ข้ามเครื่อง

เว็บเป็น static HTML/CSS/JavaScript ไม่ต้อง build และไม่ต้องใช้ API key

## GitHub Pages

ใช้ repository ชื่อ `KT-Present` และตั้ง Settings → Pages → Deploy from a branch → `main` → `/ (root)`

ภาพสไลด์และชุดคำถามตั้งต้นจะเป็นข้อมูลสาธารณะเมื่อเผยแพร่ ส่วนคำถามที่เพิ่มภายหลังในหน้าเว็บจะเก็บเฉพาะในเบราว์เซอร์ของผู้ใช้

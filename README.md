# KT-Present

เว็บซ้อมตอบคำถามพรีเซน CIP สำหรับมือถือและไอแพด

- ผู้ชมเลือกสไลด์ เปิดคำตอบ และสุ่มซ้อมได้จากลิงก์เว็บ
- ผู้แก้ไขเข้าสู่ระบบผ่านลิงก์ในอีเมลเพื่อเพิ่ม แก้ไข ลบ และเลิกทำการลบคำถาม
- คำถามที่บันทึกผ่าน Supabase จะแสดงบนทุกเครื่องที่เปิดเว็บ ส่วนสถานะการซ้อมเก็บในเบราว์เซอร์
- หากเคยแก้คำถามก่อนเปิดซิงก์ ให้เปิดเว็บจากเบราว์เซอร์เดิม เข้าสู่ระบบ แล้วกด **นำเข้าคำถามจากเครื่องนี้** เพื่อรวมเข้าชุดกลาง

เว็บใช้ HTML, CSS และ JavaScript บน GitHub Pages จาก `main` ที่ `/ (root)` และอ่านคลังคำถามสาธารณะจาก Supabase ด้วย publishable key ฐานข้อมูลอนุญาตให้แก้ไขผ่านบัญชีที่กำหนดไว้เท่านั้น
